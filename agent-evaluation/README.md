# SnapNote Agent 评测工作区

本目录集中存放 SnapNote 的 Agent/流水线离线评测、人工标注、可用性实验与结果报告。它不替代 `backend/tests` 和 `frontend/tests` 中的工程单元测试。

> SnapNote 当前是确定性流水线与模型能力的组合，并非多 Agent 架构；本目录沿用“Agent 评测”这一产品评测称呼，评测对象是从视频输入到可检索图文笔记输出的完整系统。

## 目录约定

```text
agent-evaluation/
├── TEST_PLAN.md       # 评测目标、指标口径、实验流程和验收规则
├── dataset/           # 本地视频清单、授权说明与数据集版本信息
├── annotations/       # 关键页面、重复簇、知识点和时间区间的人工标注
├── configs/           # 每轮评测的模型、Prompt、阈值和环境快照
├── scripts/           # 数据校验、批量运行、计分和报告生成脚本
├── results/           # 机器可读的逐视频、逐任务原始结果
└── reports/           # 汇总报告、图表、失败案例与对外结论
```

## 使用原则

1. 所有新建的 Agent 评测资产均放在本目录下。
2. 30 条正式测试视频一旦冻结，不再用于调参；调参另用不计入正式结果的试验视频。
3. 原始视频可能体积大且涉及版权或隐私，默认不提交 Git；提交清单、SHA-256、授权状态和标注即可。
4. 每次运行必须保留配置快照和逐样本原始结果，不能只保留最终百分比。
5. 对外数字只能从冻结数据集和锁定配置的正式运行中生成。

详细方案见 [TEST_PLAN.md](./TEST_PLAN.md)。
