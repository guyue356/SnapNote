# SnapNote 视频知识资产页 PRD

> 版本：v2.0  
> 状态：首版方案  
> 日期：2026-08-13  
> 适用端：Web（桌面端优先）  
> 核心形态：左侧原视频 + 右侧联动知识骨架

---

## 1. 产品背景

SnapNote 将视频中的语音、画面与知识内容整理为可定位、可浏览、可复用的视频知识资产。现有视频类工具通常在“完整观看”和“阅读长篇 AI 摘要”之间割裂：用户难以快速理解视频结构，也难以从摘要准确返回原视频验证上下文。

视频知识资产页需要以原视频为事实来源，以知识骨架为导航，将“看视频、找重点、读摘要、核对原文”统一在同一工作台中。

本文统一使用“画面关键帧”，不以特定媒介类型限定关键帧名称。画面关键帧可以来自 PPT、图表、Demo、网页、代码、白板、人物讲解等多种视频内容。

## 2. 产品目标

### 2.1 核心目标

1. 用户进入页面后，能够快速理解视频的整体结构与重点。
2. 用户能够通过知识骨架定位内容，并一键跳转到对应视频位置。
3. 视频播放时，知识骨架能够同步反馈当前章节和知识节点。
4. 用户能够在不离开页面的情况下查看画面、摘要与对应原文。
5. 将线性视频转化为可检索、可验证、可复制的知识资产。

### 2.2 产品原则

- 原视频是主内容和事实来源，保持最高视觉权重。
- 知识骨架是视频导航，不是长文笔记堆叠区。
- 默认提供结构概览，详细信息按需展开。
- 所有 AI 结论均应能够回到对应时间和原文验证。
- 播放器、进度条与知识骨架共享同一时间轴。

## 3. 用户场景

| 场景 | 用户任务 | 期望结果 |
| --- | --- | --- |
| 课后复习 | 快速回顾课程结构与重点 | 按章节浏览并跳转到对应讲解 |
| 会议复盘 | 查找某个结论、决策或行动项 | 通过节点类型定位并核对原话 |
| 教程学习 | 找到某个操作或 Demo | 跳转到操作开始位置并查看关键画面 |
| 内容整理 | 提取可复用的知识内容 | 复制摘要或查看完整原文 |
| 快速预览 | 不完整播放视频，先判断价值 | 通过章节和一句话摘要了解全貌 |

## 4. 页面信息架构

```text
视频知识资产页
├── 顶部栏
│   ├── 返回资产库
│   ├── 视频标题与基础信息
│   └── 导出 / 更多操作
├── 左侧：原视频区
│   ├── 视频播放器
│   ├── 播放控制
│   ├── 带 Marker 的进度条
│   └── 当前章节提示
└── 右侧：知识骨架区
    ├── 标题与浏览控制
    ├── 章节
    │   └── 知识节点
    │       ├── 收起态
    │       └── 展开态
    └── 加载 / 空 / 错误状态
```

页面默认不设置独立的长文笔记主区。详细内容依附于知识节点展开，避免与原视频争夺主视觉。

## 5. 页面布局

### 5.1 桌面端双栏布局

| 区域 | 建议占比 | 最小宽度 | 说明 |
| --- | ---: | ---: | --- |
| 左侧原视频区 | 60%–65% | 720 px | 页面主视觉，优先保证 16:9 播放体验 |
| 右侧知识骨架区 | 35%–40% | 360 px | 独立纵向滚动，不影响播放器位置 |

- 页面主体占满可用视口高度；顶部栏固定。
- 左侧播放器在可用空间内保持 16:9，背景使用中性色承接留白。
- 右栏独立滚动，播放器保持稳定可见。
- 双栏分隔线可拖动不纳入 MVP，首版采用固定比例。

### 5.2 窄屏降级

- 视口宽度小于 1024 px 时，切换为上下布局：播放器在上，知识骨架在下。
- 移动端首版只保证浏览、播放、跳转和节点展开，不追求桌面端同等信息密度。
- 播放器吸顶、浮窗播放和可拖动分栏不纳入 MVP。

## 6. 知识骨架层级

知识骨架采用三级结构：**章节 → 知识节点 → 详细内容**。

### 6.1 章节

章节表示视频中的主题阶段，是知识骨架的一级分组。

必备字段：

- 章节标题
- 起始时间
- 结束时间
- 节点数量
- 当前播放状态

交互规则：

- 点击章节标题，视频跳转到章节起始时间。
- 章节可折叠；默认展开当前章节，其余章节保持最近一次状态。
- 播放进入新章节时，仅更新高亮，不强制展开用户主动收起的章节。

### 6.2 知识节点

知识节点表示章节内可独立定位和理解的内容单元，是主要浏览和联动对象。

收起态展示：

- 时间戳
- 节点类型标识
- 节点标题
- 一句话摘要，最多两行
- 展开指示

### 6.3 详细内容

详细内容是知识节点的第二层信息，仅在用户展开节点时展示，包括画面关键帧、详细摘要和原文入口。

同一章节可包含多个知识节点；一个知识节点首版绑定一个主时间戳和一张代表性画面关键帧。

## 7. 节点展开态

节点展开后按以下顺序展示：

1. **时间戳**：显示 `MM:SS` 或 `HH:MM:SS`，点击后跳转并播放。
2. **画面关键帧**：展示与节点最相关的代表性视频画面；点击后同样跳转到对应时间。
3. **一句话摘要**：概括该节点的核心结论，收起态已展示时不重复占用视觉空间。
4. **详细摘要**：说明关键事实、过程、因果或结论，默认建议 80–200 字。
5. **查看原文**：打开该节点对应的转录片段，并高亮当前时间附近文本。
6. **复制**：默认复制“节点标题 + 时间戳 + 详细摘要”；成功后显示轻提示。

示意：

```text
▼ 03:26  [方案] 核心方案设计
  采用硬约束过滤与多维排序的两阶段策略

  ┌────────────────────────────┐
  │         画面关键帧          │
  └────────────────────────────┘

  先排除不满足路线条件的候选项，再结合距离、
  评分与绕行成本完成排序，以保证结果可用性。

  [查看原文]  [复制]
```

### 7.1 画面关键帧规则

- 画面关键帧是节点的视觉证据，不等同于 PPT 页面。
- 优先选择信息完整、清晰、稳定且与节点语义最相关的画面。
- 对人物连续讲解等无明显画面变化的节点，可展示最接近主时间戳的稳定画面。
- 无可用画面时显示统一占位，不阻断摘要和原文功能。
- 图片使用缩略图加载；点击可跳转视频，首版不提供独立图片画廊。

## 8. 播放器与知识骨架双向联动

### 8.1 骨架驱动播放器

| 用户操作 | 播放器行为 | 骨架行为 |
| --- | --- | --- |
| 点击章节 | 跳转到章节起始时间 | 高亮章节及首个有效节点 |
| 点击节点时间戳 | 跳转到节点主时间戳并播放 | 节点进入激活态 |
| 点击节点标题 | 跳转到节点主时间戳 | 节点展开并激活 |
| 点击画面关键帧 | 跳转到该画面对应时间 | 保持节点展开 |
| 点击进度条 Marker | 跳转到 Marker 时间 | 定位、展开并高亮对应节点 |

### 8.2 播放器驱动骨架

- 播放时间进入节点时间区间时，对应节点进入播放激活态。
- 右栏在自动跟随开启时，将激活节点平滑滚动至可视区域中部。
- 用户主动滚动右栏后，暂停自动跟随 8 秒，避免界面与用户争夺滚动控制。
- 用户点击“回到当前播放位置”后立即恢复自动跟随。
- 暂停视频时保留当前节点高亮。
- 拖动进度条期间不连续滚动骨架；用户释放后再定位最终节点。
- 当时间落在两个节点之间时，保持最近一个已开始节点为激活态；跨入下一章节后更新章节状态。

### 8.3 联动状态区分

- **播放激活态**：由当前播放时间决定，使用主色强调。
- **用户展开态**：由用户操作决定，可与播放激活态不同。
- **悬停态**：仅提供可点击反馈，不改变播放位置。
- 播放激活与用户展开必须解耦，避免播放过程中反复开合节点。

## 9. 进度条 Marker

Marker 将知识节点映射到播放器时间轴，帮助用户感知重点分布并快速跳转。

### 9.1 展示规则

- 每个知识节点对应一个 Marker，位置为 `节点主时间戳 / 视频总时长`。
- Marker 颜色与节点类型一致；当前节点 Marker 使用主色或放大强调。
- Marker 过密时按像素距离聚合，显示聚合点；悬停提示节点数量。
- 已播放进度、缓冲进度和 Marker 使用不同视觉层级，避免混淆。

### 9.2 交互规则

- 悬停 Marker：显示时间、类型、标题的一行浮层。
- 点击 Marker：跳转并播放，右栏定位到对应节点。
- 键盘聚焦 Marker 后可使用 Enter 跳转，保证基础可访问性。

## 10. 节点类型标识

节点类型用于快速扫读，不替代节点标题。MVP 支持以下类型：

| 类型 | 含义 | 典型内容 |
| --- | --- | --- |
| 主题 | 新主题或背景说明 | 项目背景、概念引入 |
| 观点 | 核心判断或结论 | 推荐方案、关键洞察 |
| 方法 | 方法、流程或操作步骤 | 实施路径、教程步骤 |
| 案例 | 示例、演示或具体场景 | Demo、案例拆解 |
| 数据 | 指标、图表或量化事实 | 转化率、实验数据 |
| 决策 | 明确决议或选择 | 方案确认、范围裁剪 |
| 行动项 | 后续任务及安排 | 下一步、责任分工 |

规则：

- 每个节点必须有且只有一个主类型。
- 类型由 AI 生成，低置信度时回退为“主题”。
- 类型采用“图标 + 文本/可访问标签”，不能只依赖颜色表达。
- 首版不支持用户自定义类型和多标签体系。

## 11. 交互状态

### 11.1 页面级状态

| 状态 | 展示与行为 |
| --- | --- |
| 加载中 | 播放器与骨架显示对应骨架屏，避免布局跳动 |
| 处理中 | 可播放原视频时优先开放播放；右栏展示生成进度与已完成内容 |
| 正常 | 完整展示播放器、Marker 和知识骨架 |
| 部分失败 | 保留可用内容，明确标记缺失的摘要、画面或原文 |
| 失败 | 展示失败原因、重试入口和返回资产库入口 |
| 空内容 | 视频可播放，右栏说明暂未生成知识骨架并提供重试入口 |

### 11.2 节点级状态

- 默认：展示收起态信息。
- 悬停：显示背景反馈和可点击光标。
- 展开：展示详细内容与操作。
- 播放激活：强化左侧时间轴和节点容器。
- 聚焦：显示清晰键盘焦点框。
- 内容加载：在节点内部显示局部骨架屏。
- 内容缺失：显示具体缺失项，不隐藏整个节点。
- 复制成功：按钮短暂变为“已复制”，同时显示非阻塞提示。

## 12. 首版 MVP 范围

### 12.1 必须实现

- 桌面端左视频、右知识骨架双栏布局。
- 原视频播放、暂停、拖动、倍速、音量和全屏等基础能力。
- 章节、知识节点、详细内容三级结构。
- 节点收起与展开。
- 时间戳、节点类型、标题、一句话摘要。
- 单张画面关键帧与详细摘要。
- 查看对应原文、复制节点内容。
- 点击章节、节点、关键帧和 Marker 跳转视频。
- 播放器驱动当前章节和节点高亮。
- 右栏自动跟随、用户滚动后临时暂停跟随。
- 进度条 Marker 及基本悬停提示。
- 加载、处理中、正常、空、部分失败和失败状态。
- 1024 px 以下的基础上下布局。

### 12.2 数据最小要求

每个知识节点至少包含：

```json
{
  "id": "node_id",
  "chapter_id": "chapter_id",
  "type": "method",
  "title": "核心方案设计",
  "timestamp": 206,
  "end_timestamp": 312,
  "one_line_summary": "采用硬约束过滤与多维排序的两阶段策略",
  "detail_summary": "...",
  "keyframe_url": "...",
  "keyframe_timestamp": 208,
  "transcript_start": 198,
  "transcript_end": 318,
  "transcript_text": "..."
}
```

## 13. 非目标

首版不包含：

- 独立长文笔记编辑器或富文本协同编辑。
- 多人实时协作、评论、批注和权限体系。
- 用户手动调整章节边界、节点时间轴或画面关键帧。
- 多画面关键帧轮播、图片画廊和关键帧二次裁剪。
- 自定义节点类型、多标签和复杂筛选。
- 全文语义搜索、跨视频问答和知识图谱。
- 可拖动分栏、播放器浮窗和移动端深度适配。
- AI 内容逐字事实保证；产品通过原文与时间跳转提供核验能力。

## 14. 验收标准

### 14.1 功能验收

1. 在 1440 px 桌面视口下，页面稳定呈现左侧原视频与右侧知识骨架，播放器为主要视觉区域。
2. 用户可浏览“章节 → 知识节点 → 详细内容”三级结构，并独立展开或收起节点。
3. 每个有效节点均展示时间戳、类型、标题和一句话摘要；展开后可展示画面关键帧、详细摘要、查看原文与复制。
4. 页面文案、字段和占位内容统一使用“画面关键帧”，不得以单一内容载体命名。
5. 点击章节、节点时间戳、节点标题、画面关键帧或 Marker 后，视频跳转误差不超过 1 秒。
6. 视频正常播放时，当前章节与当前节点在 500 ms 内更新高亮。
7. 自动跟随开启时，激活节点能够进入右栏可视区域；用户主动滚动后不会被立即拉回。
8. 拖动进度条时不触发骨架连续抖动，释放后只定位一次最终节点。
9. Marker 悬停可查看节点摘要信息，点击可完成视频与骨架双向定位。
10. “查看原文”展示与节点时间范围对应的转录片段；“复制”复制预期内容并给出成功反馈。
11. 画面关键帧缺失、摘要缺失或原文缺失时，页面能够局部降级且视频仍可播放。
12. 页面刷新后可恢复视频资产数据；节点展开状态无需跨刷新保留。
13. 1024 px 以下视口能够切换为可用的上下布局，无核心操作丢失。

### 14.2 体验验收

- 首屏加载后，用户无需滚动即可看到完整播放器主体、播放控制和右栏首个章节。
- 章节与节点的视觉层级明确，用户能够区分结构、内容和操作。
- 同一时刻最多有一个播放激活节点，但允许多个用户展开节点。
- 播放器进度、Marker、右栏高亮三者表达一致，不产生相互矛盾的当前位置。
- 键盘可访问时间戳、Marker、展开按钮、查看原文和复制操作。

## 15. 核心评测指标

### 15.1 AI 内容质量指标

| 指标 | 定义 | MVP 目标 |
| --- | --- | ---: |
| 章节边界准确率 | 人工判断章节切分与主题变化基本一致的比例 | ≥ 85% |
| 节点覆盖率 | 人工标注的重要内容被知识节点覆盖的比例 | ≥ 85% |
| 节点标题可理解率 | 无需播放即可理解节点主题的比例 | ≥ 90% |
| 一句话摘要有效率 | 摘要准确表达节点核心信息且无明显幻觉的比例 | ≥ 85% |
| 详细摘要事实一致率 | 摘要主要事实可由对应原文或画面支持的比例 | ≥ 90% |
| 节点类型准确率 | 主类型与人工判断一致的比例 | ≥ 80% |
| 时间定位准确率 | 节点跳转后 5 秒内进入相关内容的比例 | ≥ 90% |
| 画面关键帧相关率 | 关键帧与节点内容语义相关且可辨识的比例 | ≥ 85% |
| 原文对齐准确率 | 原文片段覆盖节点核心讲解的比例 | ≥ 90% |

### 15.2 交互与性能指标

| 指标 | 定义 | MVP 目标 |
| --- | --- | ---: |
| 视频跳转响应 | 操作至播放器开始定位的前端响应时间 | P95 ≤ 300 ms |
| 联动高亮延迟 | 播放时间变化至节点高亮更新 | P95 ≤ 500 ms |
| 节点展开响应 | 点击至展开内容可交互 | P95 ≤ 300 ms（缓存命中） |
| 骨架滚动稳定性 | 单次定位产生非预期二次滚动的会话比例 | ≤ 2% |
| 页面可用率 | 资产页核心内容成功加载的会话比例 | ≥ 99% |

### 15.3 用户价值指标

| 指标 | 说明 | 首版观察目标 |
| --- | --- | ---: |
| 首次有效定位时间 | 进入页面至首次点击节点或 Marker | 中位数 ≤ 20 秒 |
| 节点跳转使用率 | 至少使用一次知识节点跳转的资产页会话占比 | ≥ 50% |
| 原文核验使用率 | 至少打开一次“查看原文”的会话占比 | 持续观察 |
| 摘要复制使用率 | 至少复制一次节点内容的会话占比 | 持续观察 |
| 非线性观看占比 | 通过节点或 Marker 跳转产生的播放次数占比 | ≥ 40% |
| 重点定位成功率 | 用户在任务测试中找到指定内容的成功率 | ≥ 90% |

## 16. 埋点建议

MVP 至少记录以下事件：

- `asset_page_view`
- `video_play` / `video_pause` / `video_seek`
- `chapter_click`
- `knowledge_node_expand` / `knowledge_node_collapse`
- `knowledge_node_seek`
- `marker_hover` / `marker_click`
- `transcript_open`
- `node_copy`
- `auto_follow_pause` / `auto_follow_resume`
- `keyframe_load_failed`
- `asset_page_load_failed`

关键事件应携带 `asset_id`、`chapter_id`、`node_id`、`node_type`、`video_time`、`trigger_source` 和 `session_id`，用于评估内容质量与联动价值。

## 17. 首版成立标准

首版成立的最小闭环是：用户打开一个已处理视频后，可以先通过右侧知识骨架理解全貌，再通过章节、节点或 Marker 跳转到左侧原视频核验内容；视频播放时，右侧结构能够同步反馈当前位置；节点展开后，用户可以查看画面关键帧、摘要与原文并复制所需内容。

该闭环成立即代表 SnapNote 已从“AI 生成笔记”升级为“以原视频为依据、以知识结构为导航的视频知识资产”。
