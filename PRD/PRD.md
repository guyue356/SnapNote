# PRD 总集

> PRD 按文档用途独立编号。规划型 PRD 维护产品长期路线，开发型 PRD 维护可直接进入研发与验收的阶段需求；每个类别只保留最新版本入口，历史版本由 Git 追溯。

## 规划型 PRD

| 版本 | 标题 | 需求内容（详细摘要） | PRD 链接 |
|---|---|---|---|
| PRD-ROADMAP-001 | SnapNote 未来产品规划 V1.0 | 目标：规划 SnapNote 从任务结果存储升级为可检索、可引用、可治理的知识基础设施。范围：知识资产化、MiMo 内置助手、MCP 复用生态、生产化与治理四阶段。关键规则：原视频始终是事实来源，助手先检索后生成，MCP 只作为知识服务的协议适配层，权限过滤必须先于检索。异常：资产不完整时允许部分可用，证据不足时助手不得伪装成有依据，外部越权调用必须拒绝并审计。非目标：不让模型直接执行任意 SQL，不以 MCP 替代数据库、检索或权限系统。 | PRD-ROADMAP-001-SnapNote-未来产品规划.md |

## 开发型 PRD

| 版本 | 标题 | 需求内容（详细摘要） | PRD 链接 |
|---|---|---|---|
| PRD-DEV-001 | SnapNote 知识资产化一期 V1.0 | 目标：把现有任务级 JSON 和本地媒体派生为规范、可检索、可追溯、可删除的知识资产，为未来 MiMo 助手和 MCP 复用建立统一底座。范围：新任务自动构建、历史任务幂等回填、资产与版本模型、章节与原文分块、中文关键词检索、只读知识服务、最小状态与重建、删除同步。关键规则：构建失败不改变原任务完成状态，相同来源与版本不得产生重复实体，检索必须先限制资产范围并返回来源与时间坐标，删除后立即退出检索。异常：局部内容缺失时降级为部分可用，批量回填逐条隔离失败，索引异常可重建且旧可用版本不被损坏版本覆盖。非目标：本期不实现 MiMo 对话、独立搜索页、Embedding、MCP、PostgreSQL 迁移或知识图谱。 | PRD-DEV-001-SnapNote-知识资产化一期.md |
